## Build a Hooper ハイスコア攻略ガイド

![チームスピン、選手一覧、空いている能力値枠が表示されたBuild a Hooperのドラフト画面](/imgs/screenshots/draft-spin.png)

Build a Hooperの1回のランには、2種類のスコアがあります。**OVR**は完成したカードの13項目の能力値を評価し、**Legacyポイント**は、そのカードが82試合のシーズンで残した結果を評価します。

この違いを理解すると、優先順位が変わります。95 OVRのカードは評価ボーナス20ポイントですが、優勝は120ポイントです。

> まず38勝を超えられるカードを作り、その後に優勝を狙ってください。見た目が最も美しいカードが、必ずしも最高のLegacyスコアを出すとは限りません。

## 最大スコアは160 Legacyポイント

保存されたすべてのランは基本10ポイントから始まります。そこへ正規シーズンボーナス1つ、プレーオフ結果ボーナス1つ、OVRボーナス1つが加わります。

| 結果 | Legacyポイント |
| --- | ---: |
| ランを完了して保存 | 10 |
| レギュラーシーズン38勝以上 | +10 |
| プレイイン敗退 | +20 |
| 1回戦敗退 | +30 |
| カンファレンス準決勝進出 | +45 |
| カンファレンス決勝進出 | +60 |
| NBAファイナル敗退 | +90 |
| NBA優勝 | +120 |
| 最終OVR 90〜94 | +10 |
| 最終OVR 95以上 | +20 |

プレーオフボーナスは積み上がりません。優勝した場合は、それ以前のラウンドをすべて加算するのではなく、優勝ボーナス120ポイントだけを受け取ります。OVRも同様で、95以上なら90以上のボーナスと合算せず20ポイントです。

最高点の計算は次のとおりです。

```text
基本10 + 38勝ボーナス10 + 優勝120 + 95 OVRボーナス20 = 160
```

MVP、DPOY、得点王、Finals MVPなどの受賞はプロフィールに記録されますが、Legacyポイントへ直接加算されません。実績ポイントも別の仕組みです。

## OVRが勝利確率を決める

現在のシーズンエンジンは、ロックした13項目の平均評価をOVRに変換し、試合ごとの勝利確率を計算します。

```text
勝利確率 = (OVR - 60) / 50
```

レギュラーシーズンの勝率は最低25%、最高85%に制限されます。プレーオフではさらに5ポイント加算されます。各試合にはランダム要素があるため、以下は目安であり確定記録ではありません。

| OVR | レギュラーシーズン勝率 | 82試合の期待勝数 |
| --: | --: | --: |
| 80 | 40% | 33 |
| 85 | 50% | 41 |
| 90 | 60% | 49 |
| 95 | 70% | 57 |
| 97 | 74% | 61 |

実戦で重要な基準は2つです。

- **38勝** — ポストシーズンへ進み、Legacyが10ポイント増えます。
- **42勝** — プレイインを回避し、1回戦から開始します。

85 OVRは危険な境界に近く、90 OVRなら連敗に耐える余裕があります。95 OVRでも勝率70%なので、プレーオフシリーズで4敗する可能性はあります。無敗を保証する設定はありません。

## 90または95 OVRを作る方法

表示OVRでは、すべての能力値が同じ重みです。3PTがREBより大きく計算されることはなく、CLUにも隠れた倍率はありません。最終OVRは、次の13項目の平均を四捨五入した値です。

**3PT · MID · FIN · DNK · HAN · PAS · PDEF · IDEF · BLK · REB · ATH · STR · CLU**

| 評価 | 値 | 評価 | 値 |
| --- | ---: | --- | ---: |
| A+ | 97 | B | 83 |
| A | 93 | B- | 80 |
| A- | 90 | C+ | 77 |
| B+ | 87 | C | 73 |

13項目すべてがA-なら、ちょうど90 OVRです。95 OVRはさらに厳しく、A+が6個、Aが7個なら平均94.85となり、四捨五入で95になります。

ドラフトでは次の原則が役立ちます。

1. 空いている枠に入るなら、A+とAを早めに確保します。
2. A-は失敗ではなく、安全な下限と考えます。
3. 好きな役割に合うだけの理由で、序盤にB評価をロックしません。
4. 最後の数ラウンドで選択肢がなくなる前に、集めにくい能力値を補います。

3PT、FIN、HAN、ATHはスターガードやウイングから比較的見つけやすい一方、IDEF、BLK、REB、STRを後回しにすると終盤で苦しくなります。

## 評価に役割を与える

Legacyポイントでは平均OVRが勝利に大きく影響しますが、ボックススコアでは細かな能力値も意味があります。PASとHANはアシスト、REBはリバウンドに関係し、全体的な強さは得点とシーズン勝率を引き上げます。

ドラフト前に選手の役割を一文で決めてください。

- **リードガード** — HANとPASを優先し、シュートと外周守備を補います。
- **スコアリングウイング** — 3PT、MID、FIN、ATHと十分なHANを用意します。
- **ツーウェイフォワード** — PDEF、FIN、ATH、REBを軸にシュートを加えます。
- **インテリアアンカー** — REB、IDEF、BLK、STR、FINを優先します。

役割はカードを理解しやすくし、平均評価はそのカードを長いシーズンで生き残らせます。ポジション別の案は [/best-builds](/best-builds)、能力値の詳細は [/attributes](/attributes) を確認してください。

## モード別のリロール戦略

3つのモードは点数計算を変えません。ビルド中に使える情報とコントロール範囲を変えます。

### Classic

評価が見え、リロールを3回使えるため、最初の90+や95+挑戦に最適です。

単に好みでないチームだからという理由でリロールしないでください。まだ必要な能力値でA-、A、A+を提供できる選手が見当たらない場合に使います。最後の4枠のために1回残すと、終盤の悪い選択肢に対応できます。

### Blind

ポジションは見えますが評価が隠され、リロールは1回です。ハイライトの印象より既知の役割で選びましょう。ガードはPASやHAN、センターはREB、IDEF、BLKを期待しやすい選択です。

95 OVRを保証することはできません。明らかな役割の不一致を避け、平均が崩れないようにすることが目標です。

### Chaos

ポジションと評価が最後まで隠れ、リロールは1回です。確定ポジションを前提にできないため、柔軟な能力値と選手が重要になります。

純粋にLegacyポイントを狙うならClassicが最も安定します。BlindとChaosは、難しいモードの優勝や実績も同時に狙いたい場合に向いています。開始前に [/modes](/modes) の比較を確認してください。

## ハイスコア用チェックリスト

能力値をロックする前：

- ClassicでA-以上か
- 後から集めにくい枠を埋めているか
- 最後のリロールを残しているか
- 同じ選手名をすでに使っていないか
- 役割だけでなく平均評価も上げるか

シーズン開始前：

- 最終OVRが最低90あるか
- 95に届き、追加10ポイントを確保したか
- 望むスタッツのためにPAS、HAN、REBが十分か
- 保存したい場合にログインしているか

シーズン中：

- まず38勝を目標にする
- 42勝をより安定したプレーオフ進出ラインと考える
- 数ポイントのOVR差より優勝結果の方が大きな点差を生むことを忘れない
- My Cardから最後までランを送信する

## よくある失敗

**ひとつの完璧な能力値だけを追う。** A+ひとつでは複数のC評価を補えません。平均は13枠すべてを使います。

**リロールを序盤ですべて使う。** 悪い最初のスピンより、12ラウンド目でBLKやREBが空いている方が危険です。

**受賞とLegacyポイントを混同する。** 受賞はプロフィールや実績には役立ちますが、Legacy計算へ直接加算されません。

**美しいカードで満足する。** OVRは入口であり、最大の点数差はプレーオフ結果から生まれます。

**すべてのモードで同じビルドを使う。** 計算式は同じでも見える情報が違うため、ドラフト行動も変える必要があります。

## まとめ

最も短いハイスコアへの道は次のとおりです。

1. 学習中はClassicを使う
2. 13項目をA-以上で埋める
3. まず90 OVR、可能なら95 OVRを狙う
4. 38勝を超える
5. 優勝する
6. ログインした状態でランを保存する

95 OVRで優勝すれば最大160 Legacyポイントです。プレーオフには運も必要ですが、優先順位は明確になります。
