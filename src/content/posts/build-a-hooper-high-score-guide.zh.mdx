## Build a Hooper 高分攻略：95 OVR 与 160 Legacy Points

![Build a Hooper 选人界面，包含球队转盘、球员名单与待填属性槽](/imgs/screenshots/draft-spin.png)

Build a Hooper 一局里其实有两种“分数”：

- **OVR**：13 项属性的平均评分，显示在最终球员卡上。
- **Legacy Points**：球员带队打完整个赛季之后，这一局真正进入排行榜的积分。

两者不是一回事。95 OVR 只多给 20 Legacy Points；拿到总冠军则给 120 分。想拿高分，最重要的不是做一张好看的卡，而是让这套 build 进入季后赛并赢到最后。

如果你是通过 **build a hooper basketball** 或 **build a player nba** 这类搜索来到这里，先记住一句：

> 先把 13 项属性的平均值守住，再去争戒指。冠军比漂亮的 OVR 更值分。

## 单局最高是 160 Legacy Points

每个成功保存的 run 先拿 10 分，然后加入一个常规赛奖励、一个季后赛结果奖励，以及一个 OVR 奖励。

| 结果              | Legacy Points |
| ----------------- | ------------: |
| 完成并保存本局    |            10 |
| 常规赛至少 38 胜  |           +10 |
| 附加赛出局        |           +20 |
| 首轮出局          |           +30 |
| 分区半决赛        |           +45 |
| 分区决赛          |           +60 |
| 总决赛失利        |           +90 |
| NBA 总冠军        |          +120 |
| 最终 OVR 为 90–94 |           +10 |
| 最终 OVR 达到 95+ |           +20 |

季后赛奖励不会逐轮累加。总冠军拿的是 120 分，不是把首轮、半决赛和总决赛奖励全部相加。OVR 也是二选一：95+ 拿 20 分，而不是再叠一层 90+ 的 10 分。

因此，单局最高分是：

```text
10 基础分 + 10（38 胜）+ 120（总冠军）+ 20（95+ OVR）= 160
```

MVP、DPOY、得分王和 Finals MVP 会记录在个人资料中，但不会直接增加 Legacy Points。成就积分也是另一套系统。

## OVR 决定每场比赛的胜率

当前赛季引擎会计算 13 项已锁属性的平均值，再把 OVR 转成每场常规赛的获胜概率：

```text
胜率 = (OVR - 60) / 50
```

最低限制为 25%，最高限制为 85%。季后赛每场再加 5 个百分点。比赛仍然包含随机性，所以下表是期望值，不是保底战绩。

| OVR | 常规赛单场胜率 | 82 场期望胜场 |
| --: | -------------: | ------------: |
|  80 |            40% |      约 33 胜 |
|  85 |            50% |      约 41 胜 |
|  90 |            60% |      约 49 胜 |
|  95 |            70% |      约 57 胜 |
|  97 |            74% |      约 61 胜 |

这里有两个关键门槛：

- **38 胜**：进入季后赛，并获得 10 分胜场奖励。
- **42 胜**：跳过附加赛，直接从季后赛首轮开始。

85 OVR 正好处在危险线附近，一段连败就可能无缘季后赛。90 OVR 的容错明显更高。95 OVR 已经很强，但 70% 的单场概率仍可能在七场系列赛里输掉四场，不存在稳赢开关。

## 如何做到 90 或 95 OVR

13 项属性对最终 OVR 的权重完全相同。3PT 不会比 REB 更值分，CLU 也没有隐藏倍率。最终数字就是以下属性对应数值的四舍五入平均数：

**3PT · MID · FIN · DNK · HAN · PAS · PDEF · IDEF · BLK · REB · ATH · STR · CLU**

常用等级换算如下：

| 等级 | 数值 | 等级 | 数值 |
| ---- | ---: | ---- | ---: |
| A+   |   97 | B    |   83 |
| A    |   93 | B-   |   80 |
| A-   |   90 | C+   |   77 |
| B+   |   87 | C    |   73 |

13 个 A- 正好是 90 OVR。95 OVR 要难得多：6 个 A+ 加 7 个 A，平均值约为 94.85，四舍五入后才显示 95。

因此，选人时可以遵循四条简单规则：

1. 有 A+ 或 A 且能填空槽，前期通常值得直接锁。
2. A- 是可靠底线，不是失败结果。
3. 不要因为某项属性很符合球员原型，就过早锁下 B。
4. 最后几轮之前，先补齐难找的属性。

很多人很快就能填满 3PT、FIN、HAN 和 ATH，因为球星后卫与侧翼很容易提供这些强项。真正容易卡住的是 IDEF、BLK、REB 和 STR。前面完全不看内线，到了第 12 轮往往只能接受低分。

## build a player nba：先给球员一个明确角色

搜索 **build a player nba** 的人通常想解决同一个问题：怎样把 13 项零散能力拼成一个真正有角色的球员？

对 Legacy 来说，平均 OVR 决定胜率；对数据表现来说，具体属性仍然有用。PAS 与 HAN 会提高助攻，REB 会提高篮板，整体 OVR 则影响得分输出与赛季胜率。

开局先用一句话定义球员：

- **主控后卫**：HAN、PAS 优先，再补投射与外线防守。
- **得分侧翼**：3PT、MID、FIN、ATH，再留足 HAN。
- **双向锋线**：PDEF、FIN、ATH、REB，然后补投射。
- **内线支柱**：REB、IDEF、BLK、STR 和 FIN。

这才是 “build a player NBA-style” 的实用版本：先确定工作，再围绕核心属性搭建；其他槽位出现明显高分时，也不要为了角色标签拒绝价值。

更多位置路线可以看 [/best-builds](/best-builds)，全部属性解释在 [/attributes](/attributes)。

## 三种模式的 reroll 用法不同

Classic、Blind、Chaos 不会改变计分公式，只会改变选人时能看到的信息，以及手里的 reroll 数量。

### Classic

Classic 能看到完整等级，并提供 3 次 reroll，是第一次冲击 90+ 或 95+ 最合适的模式。

不要因为球队不热门就重转。当前阵容无法为尚未填充的属性提供 A-/A/A+ 时，再考虑 reroll。最好给最后四个槽位保留一次，防止尾盘被迫锁低分。

### Blind

Blind 会显示位置，但隐藏球员评分，并且只有 1 次 reroll。此时要按球员职责判断：后卫通常更适合提供 PAS、HAN；内线更可能在 REB、IDEF、BLK 上可靠。

这里很难保证 95 OVR。更现实的目标是避免明显错配，别让一两个低分把平均值直接拖垮。

### Chaos

Chaos 会同时隐藏位置和评分，直到最终揭晓，同样只有 1 次 reroll。因为无法围绕确定位置构建，应优先选择适配范围更广的球员和属性。

如果目标只是 Legacy 高分，Classic 路线最清晰；如果还要冲高难度模式戒指与成就，Blind 和 Chaos 更有价值。详细差异见 [/modes](/modes)。

## 高分检查清单

锁属性之前：

- Classic 中，这项评分是否至少为 A-？
- 它是不是后面很难补的槽位？
- 是否需要保留最后一次 reroll？
- 这个球员是否已经使用过？
- 它真的能提高平均值，还是只符合想象中的原型？

进入赛季之前：

- 最终 OVR 是否至少达到 90？
- 有没有机会冲到 95，拿额外 10 分？
- PAS、HAN、REB 是否足以支撑想要的数据表现？
- 如果要保存排行榜成绩，是否已经登录？

赛季开始之后：

- 先争取 38 胜。
- 42 胜可以避开附加赛。
- 总冠军对积分的影响远高于继续美化 OVR。
- 打完后要在 My Card 提交本局。

## 最常见的失误

**只追一个 A+。** 一个满级属性救不了多个 C，OVR 看的是 13 项平均值。

**开局就用完 reroll。** 第一轮阵容差确实难受，但第 12 轮还缺 BLK 或 REB 更难处理。

**把奖项当成 Legacy 分。** 奖项会进入个人资料和成就进度，但不会改变这一局的 Legacy 计算。

**卡做好看就结束。** OVR 只是入场券，最大的积分在季后赛结果里。

**三个模式照抄同一套决策。** 数学没有改变，但你能看到的信息变了，选人方法也必须跟着变。

## 最短高分路线

一套直接的 **build a hooper basketball** 高分路线是：

1. 先用 Classic 熟悉等级与球员。
2. 13 项属性尽量全部锁到 A- 或以上。
3. 先做到 90 OVR，有机会再冲 95。
4. 常规赛至少拿到 38 胜。
5. 争取总冠军。
6. 登录并保存本局。

95 OVR + 38 胜 + 总冠军，就是完整的 160 Legacy Points。季后赛仍然存在运气，但至少你已经把能控制的部分做对了。
