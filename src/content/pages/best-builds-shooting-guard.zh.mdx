# 最佳得分后卫构筑

得分后卫(SG) 的存在是为了得分——而在现代比赛里，还要在球停下来时仍能拉开空间、不消失。入门文章仍把外线得分、无球移动与持球压迫列为得分后卫工具箱（[位置拆解](https://halloffame-online.com/blog/basketball-positions-explained-roles-responsibilities-skills/)、[Nike 位置](https://www.nike.com/a/positions-in-basketball)）。Build a Hooper 把这套工具主要编码成 **3PT**、**MID**、**FIN**，再加够用的 **HAN** 惩罚失位。

## 位置身份

一张耐用的得分后卫表需要：

1. 一条 **主得分轴**（通常是 3PT，有时偏 MID）
2. 拒绝三分时仍能终结的方式（**FIN**，有时 **DNK**）
3. 刚好够攻击硬失位的 **HAN**
4. 可选但强大：**PDEF**，让你不在 82 场里变成累赘

公开原型工作里的无球射手角色（移动 / 定点 / 无球掩护射手）仍需要真实投篮菜单——不能只靠 ATH 化妆（[Basketball Index](https://www.bball-index.com/offensive-archetypes/)）。

## 优先级（经典）

1. **3PT**（默认），或板上拒绝三分时用 **MID**
2. **FIN** 或第二项得分技能
3. **HAN**
4. **ATH** / **CLU**
5. 双向路线的 **PDEF**

## 三条构筑路线

### 1. 移动射手（Movement Shooter）

**主项：** 3PT · ATH · HAN（够重定位与攻击）  
**次项：** MID · CLU · PDEF 残渣  
**避免：** 早期把锁定花在 BLK/REB

你是引力。协防必须飞扑过来，这张卡才工作。留一点运球，别粘死在接球点上。

### 2. 三级得分手（Three-Level Scorer）

**主项：** 3PT · MID · FIN  
**次项：** HAN · CLU · ATH  
**身份检查：** 若三级得分里空了两级，就该改名路线

这是弧内弧外都能伤人的得分后卫。更难选，经典配合时极脏。

### 3. 双向得分手（Two-Way Scorer）

**主项：** 3PT · PDEF · FIN 或 HAN  
**次项：** ATH · CLU  
**取舍：** 你会为对球防守之夜牺牲一些纯进攻

能换防的现代侧翼与大后卫在真实篮球里值钱是有原因的。游戏里，早期锁 PDEF 是你加入那个俱乐部的方式。

## 选秀阶段

| 阶段  | 目标                          |
| ----- | ----------------------------- |
| 1–4   | 装上 3PT 或 MID；别让得分空着 |
| 5–9   | 加 FIN/HAN；决定是否双向      |
| 10–13 | ATH/CLU/PDEF 胶水             |

## 模式提示

- **经典：** 公开狩猎得分轴；若那是你全部身份，没有射手的板就重随。
- **盲选：** 等级隐藏时，按名声偏好已知得分手与 3-and-D 侧翼。
- **混沌：** 纯 3PT 计划若揭成内线很脆。把投篮与 FIN 或 REB 保险配对。

## 常见错误

| 错误                  | 修正                        |
| --------------------- | --------------------------- |
| DNK 先于 3PT/FIN      | 扣篮需要到达篮下的路径      |
| 「射手」零 HAN        | 失位会吃掉你                |
| 忽视 PDEF 却抱怨防守  | 双向是路线，不是氛围        |
| 抄控球后卫的 PAS 堆法 | 多数得分后卫卡次级 PAS 就够 |

## 经典模式示例锁定顺序（移动射手）

1. 能拿到的最好 **3PT**
2. 若 3PT 已稳，再补第二得分技（**MID** 或 **FIN**）；否则继续加码三分
3. 第一次出现 B+ 及以上就锁 **HAN**
4. **ATH**
5. **CLU**
   6–13. 补 PDEF、零星 STR；若前期三分枯竭，别让 FIN 与 MID 同时空着

若 1–4 轮完全没有投篮，在经典模式里 **重随**。以 REB/BLK 开局的「移动射手」已经跑偏——改名路线或重开。

## 揭晓后的赛季检查清单

- 1–20 场：协防真的会飞扑你的三分吗，还是你只是伪装射手？
- 21–50 场：第一选择被拿走后，FIN/MID 还有第二口饭吗？
- 51–82 场：空 PDEF 的卡会被点名——你有没有留下收官用的防守？

总体评分很高但得分轴单一，预期是波动，不是稳定席位。怪模拟器之前先读 [/attributes](/attributes)。

## 何时中途改路线

- **移动射手 → 三级得分手：** 板子一直给 MID/FIN 却不给第二个 3PT——顺着走。
- **任意得分手 → 双向：** 早期出现精英 PDEF 且你的 3PT 已到 A-——锁防守。
- **SG 计划 → SF 工具：** 你在堆 REB/IDEF 而投篮很弱——你可能已经在造前锋。想想混沌揭晓风险。
