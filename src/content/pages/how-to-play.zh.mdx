## 如何玩 Build a Hooper

![复古战术海报：展示 Build a Hooper 的五阶段游戏循环](/imgs/generated/how-to-play-tactical-poster.webp)

Build a Hooper 是一款非官方浏览器篮球模拟器。你不会一开始就拿到成品球员，而是从球队赛季名单里一项一项拼技能，再把这张表放到 **82 场** 赛季里验证。本页讲的是完整循环，不是一句口号。

只想直接开玩，去 [/game](/game)。想先搞清「为什么这样选」再烧掉重随，就继续往下读。

## 五阶段完整循环

每局骨架相同。模式只改你能看到多少信息，不改顺序。

1. **选模式** — 经典（Classic）、盲选（Blind）或混沌（Chaos）（见 [模式指南](/modes)）。
2. **锁定位置** — 经典由你选；盲选先揭晓位置；混沌一直藏到结束。
3. **选秀 13 项属性** — 每轮：转一次球队赛季 → 选一名球员 → 从该球员等级里锁定一项仍空着的属性。
4. **揭晓 Hooper** — 总评与完整属性表同时出现。
5. **加入生涯球队，模拟 82 场** — 奖项、种子、季后赛，以及（若夺冠）总冠军。

这就是整款产品的循环。技巧的意义，是让你在第 3–5 阶段带着清晰身份活下来，而不是凑齐十三张互不相关的字母等级。

## 你实际在选什么

属性表始终是同一套十三项技能：

**3PT · MID · FIN · DNK · HAN · PAS · PDEF · IDEF · BLK · REB · ATH · STR · CLU**

完整词条见 [/attributes](/attributes)。首通时，可把它们当成四类工作：

| 集群        | 属性                 | 场上职责                           |
| ----------- | -------------------- | ---------------------------------- |
| 得分        | 3PT、MID、FIN、DNK   | 从三分、中投、禁区、篮上把球送进筐 |
| 组织        | HAN、PAS             | 保住球权，为队友创造机会           |
| 防守 / 篮板 | PDEF、IDEF、BLK、REB | 盯侧翼、护框、干扰、抢板           |
| 身体 / 关键 | ATH、STR、CLU        | 爆发、对抗、关键球执行             |

现代篮球分析常弱化死板的「五个位置」，改谈 **角色** —— 组织核心、自主进攻点、3-and-D 侧翼、空间型内线、护框锚点（[Basketball Index 进攻角色](https://www.bball-index.com/offensive-archetypes/)、[theScore 论混合角色](https://www.thescore.com/nba/news/1974726/forget-the-5-positions-inside-a-new-way-to-classify-nba-players)）。Build a Hooper 仍要求你在控球后卫(PG) / 得分后卫(SG) / 小前锋(SF) / 大前锋(PF) / 中锋(C) 上选秀，但表奖励的是同一思路：**先定角色，再喂这个角色真正需要的属性**。

## 逐轮选秀（真正决定一切的部分）

13 轮里，每一轮都是一次抉择：

1. 转一次 **球队赛季**（池子里有传奇与现代阵容）。
2. 对照你还缺的属性，读名单上的等级。
3. 选 **一名** 球员。
4. 从该球员身上锁定 **一项** 尚未使用的属性到你的表上。
5. 该球员与该属性在本局内耗尽，不能再用。

你不能在同一次转盘里叠五项属性，也不能离开本轮后再「留着」某名球员。游戏逼你做取舍：现在拿走 A+ 运球，还是赌下一轮还会出现组织者。

### 重随（别浪费）

各模式重随次数：

- **经典（Classic）** — 3 次球队重随
- **盲选（Blind）** — 1 次
- **混沌（Chaos）** — 1 次

当名单已经支撑不了你在前三项锁定后大声说出的那个角色时，再重随。不要只因为错过一次 A+ 就重随。赛季惩罚的是空集群，而不是次要技能上的 B+。

## 首通配方（仅经典）

新玩家应先待在经典模式，直到不看攻略也能说出一个角色。

1. 选你懂的位置 —— **控球后卫(PG)**（组织）或 **小前锋(SF)**（全能侧翼）对教学更友好。见 [/best-builds](/best-builds)。
2. 锁完三项后，说出角色：「组织核心」「双向侧翼」「禁区锚点」。说不出来，说明你只是在收集等级。
3. 前几轮优先喂该角色的 **主集群**。在第 10 轮前补上一个明确弱点。
4. 至少留一次重随，给那种对你身份毫无用处的死盘。
5. 模拟赛季时，多看第 40–60 场，别只盯开局高光。稳定胜过喧闹的第一周。

经典读得懂之后，再进盲选，再进混沌。更难的 [成就](/achievements) 阶梯刻意压在这些更暗的选秀上。

## 揭晓之后：赛季逻辑

公开球星卡不是终点。**82 场** 赛程考验的是普通夜晚。问自己：

- 到第 40、第 60 场，这个球员还说得通吗？
- 我有没有在位置每晚必做的工作上留了零分？
- 我是不是指望 CLU 创造奇迹，而整张表其余部分是空心的？
