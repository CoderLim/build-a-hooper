## 最佳中锋构筑

中锋(C) 仍拥有禁区——篮板、护框、终结——即便许多五号位如今也会拉开或传球（[Nike 论现代中锋](https://www.nike.com/a/positions-in-basketball)）。公开原型工作仍把「传统 / 锚点内线」与「全能高球权内线」当不同物种（[聚类示例](https://github.com/Cubin1215/NBA-Archetype-classification-and-performance)）。在 Build a Hooper 里，从 **REB + IDEF** 起步，再选终结者、护框者或独角兽式创造。

## 位置身份

若 REB 是空的，你就不是中锋——你是等待在玻璃上输掉赛季的高个错位。若 IDEF 与 BLK 双空，对手突破者会在禁区里住满 82 场。

## 优先级（经典）

1. **REB**
2. **IDEF**
3. **BLK** 或 **FIN**（护框者 vs 终结者分叉）
4. **STR**
5. **DNK** / **ATH** / 特色路线可选 **3PT** 或 **PAS**

## 三条构筑路线

### 1. 禁区锚点（Paint Anchor）

**主项：** REB · IDEF · BLK · STR  
**次项：** FIN（够惩罚内传）· CLU  
**故事：** 结束回合，抹掉禁区触球。经典五号位。

像赛季取决于玻璃与内线防守那样去选——因为确实取决于。

### 2. 强力终结者（Power Finisher）

**主项：** FIN · REB · STR · DNK  
**次项：** IDEF · ATH · CLU  
**风险：** 零内线防守会把胜利变成对突破者的田径赛

你在篮下与进攻篮板上得分。留够 IDEF，让对手不能在防守端无视你。

### 3. 组织型空间五号（Playmaking Stretch Five）

**主项：** PAS · 3PT 或 MID · REB  
**次项：** IDEF · HAN 残渣 · CLU  
**稀有度：** 最难路线；对混沌友好，因为技能可迁移

这是独角兽 / 枢纽内线幻想——从肘区与弧顶创造。在你扛过锚点选秀之前别尝试。即便 PAS 漂亮，REB 空仍会失败。

## 选秀阶段

| 阶段  | 目标                                     |
| ----- | ---------------------------------------- |
| 1–4   | REB + IDEF 地基                          |
| 5–9   | 选择锚点 vs 终结者 vs 空间传球手         |
| 10–13 | STR/BLK/FIN 胶水；地基之后再特色 3PT/PAS |

## 模式提示

- **经典：** 早期每次出现无聊的 REB 锁定都拿。
- **盲选：** 你知道自己是中锋——按角色标签选锚点与终结型内线。
- **混沌：** REB+IDEF+FIN 比纯 3PT 独角兽计划更能扛住得分后卫/小前锋/大前锋揭晓。

## 常见错误

| 错误              | 修正             |
| ----------------- | ---------------- |
| PAS/3PT 先于 REB  | 地基优先         |
| 把 BLK 当唯一防守 | 与 IDEF 配对     |
| 锚点忽视 FIN      | 你仍需要打进内传 |
| 把 DNK 当完整进攻 | 加 FIN/STR       |

## 经典模式示例锁定顺序（禁区锚点）

1. **REB**
2. **IDEF**
3. **BLK** 或 **STR**
4. **FIN**（足以惩罚内传即可）
5. **CLU**
   6–13. DNK/ATH 调味；**3PT/PAS** 只在地基能撑起一支真球队之后

组织型空间五号是给老玩家的后期解锁。在 REB 之前追 PAS/3PT，是独角兽梦变成 30 胜赛季的标准路径。

## 揭晓后的赛季检查清单

- 篮板：你是顶级吃板，还是仅仅很高？
- 护筐：IDEF+BLK 在改变出手选择，还是只在收集高光盖帽？
- 终结：后卫创造的简单球你能打进吗？
- 特化五号：创造/空间有没有出现——同时有没有丢掉油漆区本职？

跳过 FIN 的中锋是会打铁的纪念碑。跳过 REB 的中锋是高个侧翼。两者都很难干净地赢下 82 场。

## 为何混沌仍要先 REB

位置隐藏让特化技能变冒险，但若揭成大前锋，**REB** 与 **IDEF** 仍然有用——即便稀有地落成会冲板的超大号侧翼也仍然值钱。这种可携带性，让锚点习惯比空间五号赌博更稳。
