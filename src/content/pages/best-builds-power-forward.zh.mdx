## 最佳大前锋构筑

大前锋(PF) 夹在侧翼技能与中锋体型之间。传统入门强调篮板、内线防守与终结；现代阵容也常要求四号位拉开空间（[Nike 论进化中的内线](https://www.nike.com/a/positions-in-basketball)、[位置技能指南](https://halloffame-online.com/blog/basketball-positions-explained-roles-responsibilities-skills/)）。Build a Hooper 的大前锋卡通常靠 **REB**、**IDEF**，以及 **FIN/STR**（执法者）或 **3PT**（空间型）活着或死掉。

## 位置身份

不会抢板的大前锋，是没有侧翼工具的大个子侧翼。既护不住禁区也拉不开空间的大前锋，会变成堵车道的累赘。选一个清晰进攻职责，然后拿稳玻璃。

## 优先级（经典）

1. **REB**
2. **IDEF**
3. **FIN** 或 **STR**（执法者）_或_ **3PT**（空间型）
4. **BLK** / **MID**
5. **ATH** / **CLU**

## 三条构筑路线

### 1. 内线执法者（Interior Enforcer）

**主项：** REB · IDEF · FIN · STR  
**次项：** BLK · CLU · 轻量 MID  
**早期别追：** 若代价是玻璃，别纯追 3PT

你在两端霸凌禁区。这是传统四号位。赛季会奖励那些你差点跳过的无聊 REB 锁定。

### 2. 空间四号（Stretch Four）

**主项：** 3PT · REB · IDEF  
**次项：** MID · FIN · CLU  
**风险：** IDEF 空 + REB 空 = 每回合都输的「射手」

空间是重点——不是放弃玻璃的借口。真实阵容里的空间型内线仍要结束回合并轮转。

### 3. 跑框者（Rim Runner）

**主项：** FIN · ATH · DNK · REB  
**次项：** IDEF 残渣 · STR · CLU  
**搭档依赖：** 你要终结空接与顺下；留 REB 让打铁回来

爆发型四号。配对够用的 IDEF，别在对手低位时变成路障。

## 选秀阶段

| 阶段  | 目标                                |
| ----- | ----------------------------------- |
| 1–4   | REB 优先；启动 IDEF                 |
| 5–9   | 承诺执法者 vs 空间型 vs 跑框者      |
| 10–13 | BLK/CLU/ATH 胶水；绝不要让 REB 空着 |

## 模式提示

- **经典：** 很容易过度选进攻；强迫自己早期拿 REB/IDEF。
- **盲选：** 按角色偏好已知吃板机器与空间型内线。
- **混沌：** 若揭晓滑向中锋，REB + FIN 是最安全的大前锋/中锋保险对。

## 常见错误

| 错误                        | 修正                                  |
| --------------------------- | ------------------------------------- |
| 「空间型」在 REB 之前锁 3PT | 玻璃优先，再空间                      |
| 只有 BLK 没有 IDEF/REB      | 盖帽 ≠ 禁区套装                       |
| 执法者忽视 FIN              | 有力无手感仍会打铁                    |
| 贴大前锋标签却建成侧翼      | 若 PDEF/3PT 主导且 REB 空，去打小前锋 |

## 经典模式示例锁定顺序（内线执法者）

1. **REB**（早期不可谈判）
2. **IDEF**
3. **FIN** 或 **STR**——真内线上谁更高拿谁
4. 在不跳过篮板的前提下拿 **BLK**
5. **CLU** / **MID** 碎屑
   6–13. ATH；只有油漆区套装成型后才轻补 3PT

空间四号把第 3 步换成偏向 **3PT**，但第 1–2 步完全一样。若你说不出「我能抢板」，你就没有空间四号——只有错位侧翼。

## 揭晓后的赛季检查清单

- 对手二次进攻：你的 REB 真的在结束回合吗？
- 禁区威慑：IDEF/BLK 有出场，还是突破者免费租住？
- 空间四号：你的 3PT 是否拉开突破车道，还是假空间？

执法者卡若跳过 FIN，在选秀房看起来很硬，补篮时很软。怪席位之前先修。

## 盲选 / 混沌提示

等级隐藏时，优先选已知玻璃优先的前锋与终结型内线。没有 REB 保险的「空间」名声，是混沌揭成中锋空洞的常见路径。把 **REB + FIN** 当作可携带的大前锋/中锋套装。
