## 最佳小前锋构筑

小前锋(SF) 是摇摆位置：够高惩罚错位，够技能活在外线。教练与球探仍把现代侧翼当作最贵的双向原型——接球投引力、换防、次级创造、对抗终结（[HoopBrief 侧翼特质](https://hoopbrief.com/blog/what-nba-scouts-look-for-in-wings)）。在 Build a Hooper 里，这套栈主要是 **3PT + PDEF + FIN/ATH**；若要组织前锋风味，再加可选的 **HAN/PAS**。

## 位置身份

到第五次锁定时自问：

- 我拉开空间吗？→ **3PT**
- 我扛得住换防吗？→ **PDEF**（以及 ATH）
- 我能把优势终结吗？→ **FIN**（DNK 可选）
- 我创造吗？→ 只有当你选了组织前锋路线

小前锋对单个空洞的惩罚比控球后卫/中锋轻——所以它是很好的学习位置——但两个空洞仍会沉赛季。

## 优先级（经典）

1. **3PT**
2. **PDEF** _或_ **FIN**（尽早决定 3-and-D 还是砍刀）
3. **ATH**
4. 视路线选 **REB** 或 **HAN**
5. **CLU** / **STR**

## 三条构筑路线

### 1. 3-and-D 侧翼

**主项：** 3PT · PDEF · ATH  
**次项：** REB · CLU · 轻量 FIN  
**故事：** 引力 + 换防。最「现代 NBA」的小前锋卡。

在珠宝属性之前先拿稳投射与外线防守。这条路线映射每个球探办公室仍想要的侧翼。

### 2. 砍刀前锋（Slashing Forward）

**主项：** FIN · ATH · DNK 或 STR  
**次项：** 3PT（留一点空间）· HAN · CLU  
**风险：** 零 3PT 会让协防在 82 场里坐进禁区

你活在下坡。留一点 3PT，让防守不能免费堵车道。

### 3. 组织前锋（Point Forward）

**主项：** HAN · PAS · 3PT  
**次项：** PDEF · FIN · CLU  
**身份检查：** 若 PAS 与 HAN 都弱，你就不是组织前锋

来自侧翼的次级创造。更难选，但对盲选/混沌极友好，因为位置模糊时组织能迁移。

## 选秀阶段

| 阶段  | 目标                             |
| ----- | -------------------------------- |
| 1–4   | 3PT + 启动 PDEF 或 FIN           |
| 5–9   | 承诺一条路线；加 ATH             |
| 10–13 | REB/CLU/STR 胶水；避免第二个空洞 |

## 模式提示

- **经典：** 学习位置首选——小前锋原谅单项偏软。
- **盲选：** 选已知双向或创造型侧翼；等级藏着，角色不藏。
- **混沌：** 若位置可能滑向得分后卫或大前锋，3PT+FIN+PDEF 是最安全的三角。

## 常见错误

| 错误                        | 修正                            |
| --------------------------- | ------------------------------- |
| 建控球后卫式 PAS 却没有 HAN | 组织前锋需要两件工具            |
| 纯 DNK/ATH 却 3PT 全空      | 加空间，或接受禁区拥堵          |
| 「明星得分」小前锋跳过 PDEF | 82 场包含防守                   |
| 早期拉满 BLK                | 很少是你的工作——后期捡 REB 残渣 |

## 经典模式示例锁定顺序（3-and-D 侧翼）

1. **3PT**
2. **PDEF**
3. **ATH**（若板上 ATH 很差则先 FIN）
4. 轻量 **FIN** 或 **REB**
5. **CLU**
   6–13. STR、次级 HAN；别让组织与终结同时空窗

把 3-and-D 当成「只会投三分」就会失败。没有 ATH/PDEF 的换防是扮演。没有终结工具的投篮会在被逼离弧顶时饿死——这正是球探仍在打分的侧翼课题（[HoopBrief](https://hoopbrief.com/blog/what-nba-scouts-look-for-in-wings)）。

## 揭晓后的赛季检查清单

- 到第 25 场，对手尊重你的外线吗？
- 换防到更快后卫时你能活吗（PDEF/ATH）？
- 若选了组织前锋，助攻/决策有出现，还是只买了空壳 PAS？

小前锋能原谅一项软弱技能，不能原谅同一簇里的两项空洞。

## 专属于 SF 的混沌提示

位置隐藏时，**3PT + FIN + PDEF** 三角比纯组织前锋 PAS 堆更能扛住揭成 SG 或 PF。把独角兽式组织留给你负担得起风险的经典模式。
