## Build a Hooper 模式

![复古三联战术海报：对比清晰、隐藏和混沌的篮球选秀信息](/imgs/generated/modes-tactical-poster.webp)

模式不会改写十三项属性。它们改变的是 **信息量** 与 **重随预算**。选秀骨架相同，战争迷雾不同。若是新手，先读 [/how-to-play](/how-to-play)，再回来决定这道谜题要多难。

## 速览对比

| 模式                | 位置     | 选秀时评分   | 球队重随 | 适合                   |
| ------------------- | -------- | ------------ | -------- | ---------------------- |
| **经典（Classic）** | 你来选   | 可见         | 3        | 学习集群与角色身份     |
| **盲选（Blind）**   | 先揭晓   | 藏到最终揭晓 | 1        | 不做等级逛街、敢于承诺 |
| **混沌（Chaos）**   | 藏到结束 | 藏到结束     | 1        | 凭直觉选秀与高难成就   |

buildahooper.org 目前没有单独的「每日」模式。竞争压力来自盲选 / 混沌、[排行榜](/leaderboard)，以及把混沌/盲选总冠军算得比经典刷分更重的 [成就](/achievements)。

## 经典 — 完整球探报告

经典是最干净的课堂。你选控球后卫(PG) / 得分后卫(SG) / 小前锋(SF) / 大前锋(PF) / 中锋(C)，名单上每位球员的字母等级都看得见，并保留三次重随。

**怎么打**

- 尽早命名角色（组织核心、移动射手、禁区锚点）。现代球探语言更爱角色而非死板位置框——即便在五位置选秀里也很有用（[Nike 位置入门](https://www.nike.com/a/positions-in-basketball)、[Hall of Fame Online 位置技能](https://halloffame-online.com/blog/basketball-positions-explained-roles-responsibilities-skills/)）。
- 用可见等级先填满 **主集群**，再补一个弱点。
- 把重随花在空板上，而不是追逐每一次 A+。

**经典何时骗你**

看见所有等级会诱发贪婪。有人把得分拉满却忘了运球，或建成一堵墙却没有终结。赛季仍是 82 场。经典教你读表，但不会原谅空心身份。

## 盲选 — 位置已知，等级全黑

盲选先揭晓你的位置，然后把评分藏到最终揭晓。你只有一次重随。

**怎么打**

- 按 **位置职责** 选秀，而不是去找你看不见的字母等级。
- 偏好已知角色匹配该位置的球员——控球后卫选组织者，小前锋选能投能防的侧翼，中锋选吃板机器——即便数字被涂黑。
- 留一条备选技能路径。若前五轮在控球后卫局里完全不出组织，就转向得分后卫式身份，而不是恐慌烧掉唯一一次重随。

**为何存在盲选**

真实球探也常常面对不完整的板。你先知道职责（控球后卫），再知道今晚精确的技能等级。盲选训练这种习惯。若干成就阶梯只统计混沌/盲选冠军——刷经典清不完整块板。

## 混沌 — 在黑暗里构筑

混沌把位置与评分都藏到结束。一次重随。依赖完美信息的构筑会在这里故意崩掉。

**怎么打**

- 选 **均衡集群**，而不是只在一个位置才成立的极度特化狙击手。
- 偏好能跨位置存活的属性：终结 + 运动能力 + 一项组织 + 一项防守，比纯接球投、禁区工具全空的表更能扛住位置揭晓。
- 接受方差。混沌属于已经在经典与盲选里扛过死盘而不崩溃的玩家。

**混沌与成就**

若你在意完整 Hooper、冷门夺冠，或漫长的混沌/盲选总冠军阶梯，混沌不是可选风味——它是刷成就的主线。见 [/achievements](/achievements)。

## 按选秀阶段的模式策略

### 第 1–4 轮 — 身份

- 经典：锁定定义角色的两三项属性。
- 盲选 / 混沌：锁定可迁移技能（视板面选 HAN、FIN 或 REB），避免把自己锁死在单一投篮菜单上。

### 第 5–9 轮 — 覆盖

补上该位置每晚必须完成的工作。控球后卫没有 PAS/HAN、中锋没有 REB/IDEF、得分后卫没有得分轴——即便总评好看，长赛季也会垮。

### 第 10–13 轮 — 胶水

填洞。CLU 在后期很有价值，但替代不了空掉的主集群。当表上已有真实进攻或防守职责时，ATH 与 STR 才更重要。

## 常见错误

| 错误                     | 为何伤人               | 修正               |
| ------------------------ | ---------------------- | ------------------ |
| 第一天就跳进混沌         | 学到的是恐慌，不是角色 | 经典 → 盲选 → 混沌 |
| 经典重随在第 6 轮前烧光  | 后期死板逼你坏锁       | 留一次应急重随     |
| 把经典狙击手原样抄进混沌 | 隐藏位置惩罚单音符表   | 选多职责属性       |
| 忽视模式门槛成就         | 半块板永远锁着         | 穿插盲选/混沌夺冠  |
