# 十三项属性详解

![复古战术海报：匿名球员周围连接十三项篮球属性节点](/imgs/generated/attributes-tactical-poster.webp)

每张 Build a Hooper 属性表都填同一套十三项等级。模式改变你看见什么。位置改变你该优先哪些等级。属性本身不变：

**3PT · MID · FIN · DNK · HAN · PAS · PDEF · IDEF · BLK · REB · ATH · STR · CLU**

本页是百科。首通排序用 [/how-to-play](/how-to-play)。位置优先级用 [/best-builds](/best-builds)。

游戏中的字母等级是粉丝模拟、映射自参考评分集——示意性内容，非官方 NBA 或 2K 数据。

## 怎么读这张表

按 **集群** 思考，而不是十三次互不相关的升级：

1. **得分** — 3PT、MID、FIN、DNK
2. **组织** — HAN、PAS
3. **防守 / 篮板** — PDEF、IDEF、BLK、REB
4. **身体 / 关键** — ATH、STR、CLU

强卡会强化一个集群，再从第二个集群借力。组织全空却投篮华丽，第一选项被拿掉就会死。禁区防守顶级却没有终结，进攻会卡住。这是篮球，不只是游戏规则——阵容构建研究一再发现互补角色的同一需求（[Frontiers 论原型搭配](https://www.frontiersin.org/journals/sports-and-active-living/articles/10.3389/fspor.2025.1639431/full)）。

锁完三项后，大声说出角色。说不出来，说明你只是在收集等级。

## 得分集群

### 3PT — 三分投射

**场上：** 拉开空间。迫使协防尊重弧顶，突破与低位才有空气。

**选秀里：** 得分后卫与空间型内线优先；现代控球后卫/小前锋价值也高。后卫 3PT 很低，又缺 MID/FIN，等于没有得分轴。

**选秀提示：** 若 HAN 是空的，别只叠定点角球射手——移动与急停创造也需要运球（[Basketball Index 移动 / 无球射手角色](https://www.bball-index.com/offensive-archetypes/)）。

### MID — 中距离

**场上：** 急停、肘区、短距离后仰。在真实分析辩论里不如三分时髦，但当弧线被覆盖、半场需要两分时仍有用。

**选秀里：** 与 3PT 搭配成三级得分手；与 FIN 搭配成中低位前锋。纯 MID、既无空间也无禁区威胁，在 82 场里更容易被针对。

**选秀提示：** 若板上一直不出 3PT，MID + FIN 仍能喂养得分后卫/小前锋得分手——尤其在盲选里你没法逛街挑弧线时。

### FIN — 终结

**场上：** 上篮、抛投、对抗下的篮下手感。不等于扣篮集锦。

**选秀里：** 近乎通用价值。攻击失位的后卫、空切侧翼、顺下内线都需要。FIN 空、DNK 高，看起来能飞，简单球仍会打铁。

**选秀提示：** 比自尊心允许的更早拿 FIN。赛季会暴露只会在空旷处扣篮的人。

### DNK — 扣篮 / 篮上终结

**场上：** 垂直威胁、空接、二次进攻权威。华丽，但情境性强。

**选秀里：** 与 ATH、FIN 互补，适合砍刀与跑框者。作为唯一得分技能很弱——你仍需要到达篮下的路径（HAN/ATH），或顺下语境（挡拆；本模拟里队友 PAS 你无法同等控制）。

**选秀提示：** DNK 是调味属性。别让它抢走本该属于你角色的 REB 或 PAS 锁定。

## 组织集群

### HAN — 运球 / 控球安全

**场上：** 活球运球、摆脱压迫、不开局就失误地发起进攻。

**选秀里：** 主控持球者不可谈判。任何自主进攻点都高价值。纯顺下内线优先级较低——但混沌选秀仍应留一点 HAN，因为位置可能揭成后卫。

**选秀提示：** 控球后卫局里跳过 HAN 去追 3PT，赛季变硬时常会崩。没有球的「创造」不算创造。

### PAS — 传球 / 组织

**场上：** 助攻、大斜线、口袋传球、决策速度。

**选秀里：** 组织核心活在这里。组织前锋与组织型内线（[NetStats 风格角色讨论](https://netstats.dev/archetypes) 里的枢纽画像）也偏 PAS。得分后卫可靠次级 PAS 存活；高球权控球后卫 PAS 全空，是长赛季大问题。

**选秀提示：** 没有 HAN 的 PAS 仍能帮助接球后出球。没有 PAS 的 HAN 只会做出单打卡。控球后卫在可能的情况下，第 9 轮前尽量拿齐两者。

## 防守 / 篮板集群

### PDEF — 外线防守

**场上：** 限制持球者、挤过掩护、干扰接球投。能换防 1–3 的侧翼活在这里；现代侧翼球探笔记把换防能力当作选秀区分项（[HoopBrief 侧翼特质](https://hoopbrief.com/blog/what-nba-scouts-look-for-in-wings)）。

**选秀里：** 得分后卫/小前锋双向构筑优先；小控球后卫也有用。内线若 IDEF/BLK/REB 顶尖可放低——但盲选/混沌混合构筑别把它清零。

### IDEF — 内线防守

**场上：** 禁区存在感、低位限制、不一定每次盖帽也能吓阻突破。

**选秀里：** 大前锋/中锋锚点核心。放弃 IDEF 的空间型四号位，对手把体型停在内线时会成累赘。后卫很少主堆 IDEF，除非做新奇锁死卡。

### BLK — 盖帽

**场上：** 护框事件与身后协防轮转。

**选秀里：** 与 IDEF 互补，构成真锚点。BLK 高、REB 空，仍会输掉长回合。把 BLK 当作内线防守的高光兄弟，而不是完整禁区套装。

### REB — 篮板

**场上：** 结束回合、创造二次进攻、惩罚小阵容。

**选秀里：** 中锋强制，大前锋近乎强制。敢冲板的侧翼可用中等 REB。后卫通常最后捡残渣——除非混沌揭成大个子，而你没建玻璃。

## 身体 / 关键集群

### ATH — 运动能力

**场上：** 第一步、回防速度、转换爆发、功能性弹跳。

**选秀里：** 砍刀、压迫防守者、跑框者的乘数。ATH 低、FIN 高，技巧型终结者仍可行；ATH 低、PDEF 高，很难贴住人。

### STR — 力量

**场上：** 卡位、对抗终结、低位杠杆、掩护耐久。

**选秀里：** 内线与身体型侧翼喜爱。纯空间手可少一点。自称「禁区恶霸」却 STR 全空，是赛季会注意到的矛盾。

### CLU — 关键球 / 收官执行

**场上：** 回合变少时的关键投篮与沉着。

**选秀里：** 每个位置都有价值的收官者。坏陷阱：主集群还空着就早锁 CLU。关键球不会发明你从未建过的投篮菜单。

**选秀提示：** 角色成真后再在后半段瞄 CLU——除非经典里出现一次本局难得的 A+ CLU，且捐献者其余项也合适。

## 什么最重要？

没有通用排名。位置与角色决定：

| 若你在建…        | 早期倾向…                        |
| ---------------- | -------------------------------- |
| 组织核心控球后卫 | HAN、PAS，然后 3PT 或 MID        |
| 得分型得分后卫   | 3PT 或 MID + FIN，然后 HAN       |
| 3-and-D 侧翼     | 3PT + PDEF，然后 ATH/REB         |
| 禁区大前锋/中锋  | REB + IDEF，然后 FIN/STR/BLK     |
| 混沌未知位置     | FIN 或 REB + 一项组织 + 一项防守 |

跨角色来看，空掉的 **组织** 或空掉的 **终结**，最常在第 60 场左右毁掉「总评很漂亮」的表。
