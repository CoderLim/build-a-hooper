## 按位置最佳构筑

![复古半场战术海报：展示五个互补的篮球位置](/imgs/generated/best-builds-tactical-poster.webp)

这些指南把真实篮球 **职责** 翻译成 Build a Hooper 的十三项属性表。它们不承诺完美总评或不败赛季。它们是角色模板：早期锁什么、后期补什么，以及哪些现代原型能干净映射到控球后卫(PG) / 得分后卫(SG) / 小前锋(SF) / 大前锋(PF) / 中锋(C)。

依据来自公开的角色写作——组织核心与自主进攻点、3-and-D 侧翼、空间型内线、护框锚点——而不是照抄另一粉丝站的权重表（[Basketball Index 角色](https://www.bball-index.com/offensive-archetypes/)、[位置技能入门](https://halloffame-online.com/blog/basketball-positions-explained-roles-responsibilities-skills/)、[侧翼球探特质](https://hoopbrief.com/blog/what-nba-scouts-look-for-in-wings)）。

## 稳定性原则

跨过 82 场，一张连贯的 B+/A- 表，胜过运球或篮板全空的混沌 A+ 高光集锦。真实阵容研究一再发现同一模式：球队需要互补角色，而不是十三条满分数据栏（[原型搭配研究](https://www.frontiersin.org/journals/sports-and-active-living/articles/10.3389/fspor.2025.1639431/full)）。

用 Build a Hooper 的话说：

1. 第三次锁定时说出角色。
2. 喂它的主集群。
3. 补上该位置每晚都会面对的一个弱点。
4. 让 CLU 与调味属性靠后。

## 模式如何改写这些构筑

- **经典** — 按深度指南字面执行；你看得见等级。
- **盲选** — 保持相同优先级，但等级隐藏时按已知角色选捐献者。
- **混沌** — 偏向能扛住多种位置揭晓的属性（FIN、REB、HAN、PDEF）。极度特化狙击手更容易碎。
