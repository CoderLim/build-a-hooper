## Best Small Forward Build

Small forward is the swing position: tall enough to punish mismatches, skilled enough to live on the perimeter. Coaches and scouts still treat the modern wing as the most valuable two-way archetype — catch-and-shoot gravity, switch defense, secondary creation, finishing through contact ([HoopBrief wing traits](https://hoopbrief.com/blog/what-nba-scouts-look-for-in-wings)). In Build a Hooper that stack is mostly **3PT + PDEF + FIN/ATH**, with optional **HAN/PAS** if you want point-forward flavors.

## Position identity

Ask by lock five:

- Do I space? → **3PT**
- Do I survive switches? → **PDEF** (and ATH)
- Do I finish advantages? → **FIN** (DNK optional)
- Do I create? → only if you chose the Point Forward route

SF punishes one empty hole less than PG/C — that is why it is a great learning position — but two empty holes still sink seasons.

## Priority order (Classic)

1. **3PT**
2. **PDEF** _or_ **FIN** (decide 3-and-D vs slasher early)
3. **ATH**
4. **REB** or **HAN** depending on route
5. **CLU** / **STR**

## Three build routes

### 1. 3-and-D Wing

**Primary:** 3PT · PDEF · ATH  
**Secondary:** REB · CLU · light FIN  
**Story:** Gravity + switches. The most “modern NBA” SF card.

Secure shooting and perimeter D before jewelry attributes. This route maps to the wing every front office still wants.

### 2. Slashing Forward

**Primary:** FIN · ATH · DNK or STR  
**Secondary:** 3PT (keep some spacing) · HAN · CLU  
**Risk:** Zero 3PT makes help defense sit in the paint for 82 games

You live downhill. Keep a dab of 3PT so the defense cannot clog the lane without paying.

### 3. Point Forward

**Primary:** HAN · PAS · 3PT  
**Secondary:** PDEF · FIN · CLU  
**Identity check:** If PAS and HAN are both weak, you are not a point forward

Secondary creation from the wing. Harder draft, excellent Blind/Chaos flexibility because creation travels when positions blur.

## Draft phases

| Phase | Goal                                  |
| ----- | ------------------------------------- |
| 1–4   | 3PT + start PDEF or FIN               |
| 5–9   | Commit to a route; add ATH            |
| 10–13 | REB/CLU/STR glue; avoid a second hole |

## Mode notes

- **Classic:** Best place to learn because SF forgives a single soft skill.
- **Blind:** Draft wings who are known two-way or creators; grades hide but roles do not.
- **Chaos:** 3PT+FIN+PDEF is the safest triangle if position might slide toward SG or PF.

## Common mistakes

| Mistake                           | Fix                                     |
| --------------------------------- | --------------------------------------- |
| Building PG PAS without HAN       | Point forward needs both tools          |
| Pure DNK/ATH with empty 3PT       | Add spacing or accept paint congestion  |
| Skipping PDEF on “star scorer” SF | 82 games include defense                |
| Maxing BLK early                  | Rarely your job — take REB crumbs later |

## Sample Classic lock order (3-and-D Wing)

1. **3PT**
2. **PDEF**
3. **ATH** (or FIN if ATH is trash on the board)
4. Light **FIN** or **REB**
5. **CLU**
   6–13. STR, secondary HAN, never zero out both creation _and_ finishing

3-and-D fails when you treat it as “only threes.” Switch defense without ATH/PDEF is cosplay. Shooting without a finish tool dies on closeouts that run you off the line — exactly the wing problem scouts still grade ([HoopBrief](https://hoopbrief.com/blog/what-nba-scouts-look-for-in-wings)).

## Season checklist after reveal

- Do opponents respect your arc by game 25?
- Can you survive a switch onto a quicker guard (PDEF/ATH)?
- If you chose Point Forward, are assists/decisions showing up, or did you only buy empty PAS?

SF is forgiving of one soft skill. It is not forgiving of two soft skills in the same cluster.

## Chaos tip unique to SF

If position is hidden, the SF triangle **3PT + FIN + PDEF** survives SG and PF reveals better than a pure Point Forward PAS stack. Save unicorn creation for Classic once you can afford the risk.
